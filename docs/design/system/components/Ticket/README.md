The boarding ticket: green header with route, key facts, a perforation and the QR code with the booking reference. The QR here is a sample pattern.

- Props: `carrier`, `status`, `statusLabel`, `from`, `fromStation`, `to`, `toStation`, `date`, `time`, `seat`, `passenger`, `reference`, `offline` (label shown when saved on the device), `labels` (localized field names).
- The QR always sits on white for scanners, at least 168px. Show the reference in `data-large`, LTR-isolated.
