Material Symbols Rounded (weight 400, optical size 24) as inline SVG that inherits `currentColor`.

- Props: `name` (one of the bundled names, see `Masslak.ICONS`), `size` (default 24), `flip` (mirror in RTL; use for directional icons only).
- Do: give icon-only buttons an accessible label; use 20px in dense UI, 24px by default.
- Don't: mirror clocks, checkmarks, QR or media icons.
