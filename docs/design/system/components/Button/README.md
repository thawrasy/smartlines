Pill-shaped buttons in five emphasis levels: filled, tonal, outlined, text, plus wheat for money actions and danger for destructive ones.

Use exactly one `filled` button per view for the main action. Label buttons with the action and, for payments, the amount.

- Props: `variant` (filled, tonal, outlined, text, wheat, danger), `size` (sm, md, lg), `icon`, `trailingIcon`, `block`, `disabled`, plus native button props.
- Heights: `size-control-sm`, `size-control`, `size-control-lg`. Mobile checkout uses `lg` and `block`.
- Don't: use "OK", "Submit" or "Yes"; put two filled buttons side by side.
